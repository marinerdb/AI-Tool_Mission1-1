- [x] 모델 세 종 선정: `Claude Sonnet 5.5`, `Gemini`, `GPT-6` 세 가지 모델로 선정
- [x] 비교 기준 확정: `형식 준수`, `사실 정확성`, `직무 연관성의 근거성`, `지어내지 않기` 넷으로 좁힘
- [x] 모델 세 종 비교: 4개 기준별로 모델마다 1~5점을 매기고, 응답의 어느 부분 때문인지 근거를 문장으로 적음 (model-comparison.md)
- [x] 모델 선정: 점수와 비교 결과를 기반으로, 사용할 모델 하나를 고르고 선정 이유를 작성
- [x] 페르소나와 시스템 프롬프트 v1 검토: 이름, 역할, 전문 분야, 말투, 금지 사항, 우선순위를 확인하고 필요한 부분을 수정
- [x] Few-shot 예시와 입력 템플릿 검토: 예시 3건(되묻기 1건 포함)과 템플릿 1개를 확인하고 필요하면 고침
- [x] 검증 전략과 환각 검증 질문 확정: 의심할 오류 유형을 정하고, 질문 10건의 정답을 기사 원문과 대조해 확정
- [x] Zero-shot 실행: 예시 없이 규칙만 있는 시스템 프롬프트 v1로 같은 기사를 정리시키고 결과 저장
- [x] Few-shot 실행: v1에 예시 3건을 붙인 프롬프트로 같은 기사를 정리시키고 결과 저장
- [x] Zero-shot과 Few-shot 비교 기록: 형식, 3줄 유지, 되묻기 동작의 차이를 정리하고 단계적 추론 유도 추가 여부와 이유를 직접 작성

- [x] 프롬프트 v2 작성: 표시한 지점(없으면 지시와 가장 어긋난 응답 하나)을 줄이도록 v1을 고치고, 무엇을 왜 고쳤는지 작성
- [x] v2 재실행: 문제가 된 입력을 v2로 다시 돌려 개선됐는지 확인하고 결과 기록
- [x] 카테고리 표시: 프롬프트 3건 이상에 "페르소나" 또는 "텍스트 생성"을 표시
- [x] 미해결 과업 2건 정리: 프롬프트를 고쳐도 안 된 과업을 골라 시도한 프롬프트 원문과 막힌 이유를 직접 작성
