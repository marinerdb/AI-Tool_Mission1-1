# LLM 모델 비교와 선정 보고서

## 1. 과업

기업 분석용 뉴스 기사에서 3줄 요약과 IT/개발 직무 연관성을 추출한다.

## 2. 비교 방법

- 세 모델에 동일한 과업 프롬프트를 입력했다.
- 각 모델당 같은 입력으로 1회 실행하고 결과를 그대로 저장했다.
- 점수는 1~5점이며 클수록 좋다. 점수와 근거는 기사 원문과 직접 대조해 매긴다.

## 3. 비교 대상 모델

| 모델 이름                 | 버전                                                              | 실행 시점 | 무료 요금제 사용 가능 |
| ------------------------- | ----------------------------------------------------------------- | --------- | --------------------- |
| 모델 A: Claude Sonnet 5.5 | Sonnet 5.5                                                        |           | X                     |
| 모델 B: Gemini            | 정확한 내부 버전 번호·모델 코드명은 서비스에서 따로 안내되지 않음 |           | O                     |
| 모델 C: GPT-6             | GPT-6                                                             |           | O                     |

> 무료 요금제로 사용할 수 있는 모델: **모델 B(Gemini), 모델 C(GPT-6)** (2개)

## 4. 비교표

| 비교 기준            | 정의                                               | 모델 A | 모델 B | 모델 C | 근거 |
| -------------------- | -------------------------------------------------- | ------ | ------ | ------ | ---- |
| 형식 준수            | 요약이 정확히 3줄, 직무 연관성·확인 필요 항목 포함 |        |        |        |      |
| 사실 정확성          | 수치·날짜·기업명이 원문과 일치 (오류 건수)         |        |        |        |      |
| 직무 연관성의 근거성 | 기사 내용에 근거해 적고 추론은 구분                |        |        |        |      |
| 지어내지 않기        | 기사에 없는 정보를 만들지 않고 '확인 불가'로 처리  |        |        |        |
