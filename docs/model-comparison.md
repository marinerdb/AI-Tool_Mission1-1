# LLM 모델 비교와 선정 보고서

## 1. 과업

기업 분석용 뉴스 기사에서 3줄 요약과 IT/개발 직무 연관성을 추출한다.

- 비교에 사용한 기사: 파이낸셜뉴스 2026-06-18 「스터닝밸류 "현대오토에버, 아틀라스 상용화시 수혜...AI데이터 플랫폼 기업 재평가"」

## 2. 비교 방법

- 세 모델에 동일한 과업 프롬프트를 입력했다.
- 각 모델당 같은 입력으로 1회 실행하고 결과를 그대로 저장했다.
- 점수는 1~5점이며 클수록 좋다. 점수와 근거는 기사 원문과 직접 대조해 매긴다.

## 3. 비교 대상 모델

| 모델 이름                 | 버전                                                              | 실행 시점        | 무료 요금제 사용 가능 |
| ------------------------- | ----------------------------------------------------------------- | ---------------- | --------------------- |
| 모델 A: Claude Sonnet 5.5 | Sonnet 5.5                                                        | 2026-11-25 16:21 | X                     |
| 모델 B: Gemini            | 정확한 내부 버전 번호·모델 코드명은 서비스에서 따로 안내되지 않음 | 2026-11-25 16:22 | O                     |
| 모델 C: GPT-6             | GPT-6                                                             | 2026-11-25 16:22 | O                     |

> 무료 요금제로 사용할 수 있는 모델: **모델 B(Gemini), 모델 C(GPT-6)** (2개)

## 4. 비교표

| 비교 기준            | 정의                                               | 모델 A | 모델 B | 모델 C | 근거                                                               |
| -------------------- | -------------------------------------------------- | ------ | ------ | ------ | ------------------------------------------------------------------ |
| 형식 준수            | 요약이 정확히 3줄, 직무 연관성·확인 필요 항목 포함 | 5      | 5      | 4      | A, B는 형식을 다 지켰고 C는 기업/이슈에 불필요한 기호(`-`)를 붙임  |
| 사실 정확성          | 수치·날짜·기업명이 원문과 일치 (오류 건수)         | 5      | 5      | 3      | C만 2건 오류. 아틀라스를 오토에버 사업처럼 씀, 전망을 사실처럼 씀  |
| 직무 연관성의 근거성 | 기사 내용에 근거해 적고 추론은 구분                | 5      | 4      | 2      | A는 전부 (추론) 표시, B는 직무명이 두루뭉술, C는 7개 중 1개만 표시 |
| 지어내지 않기        | 기사에 없는 정보를 만들지 않고 '확인 불가'로 처리  | 5      | 5      | 3      | C는 "추진하고 있음"처럼 기사보다 강하게 씀                         |

## 5. 최종 선정 결론

- 선정 모델: 모델 A (Claude)
- 선정 근거: A는 오류가 없고 추론을 전부 표시해서 기사 내용과 구분이 잘 됐다. 형식은 프롬프트로 고칠 수 있지만 사실을 단정하는 문제는 고치기 어려워서 A를 골랐다.

비교 대상 모델 중, 무료 요금제로 사용할 수 있는 모델은, 모델 B(Gemini)와 모델 C(GPT-6)로 두 가지이다.
