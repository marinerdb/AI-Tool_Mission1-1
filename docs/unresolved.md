# 미해결 기록

## [미해결 1] 기사 URL만 주고 정리시키기

**시도한 프롬프트 (원문):**

```
다음 뉴스 기사를 기업 분석 용도로 정리해 줘. 기사 본문에 있는 내용만 근거로 삼아야 해.

[기사]
기사 제목: 스터닝밸류 "현대오토에버, 아틀라스 상용화시 수혜...AI데이터 플랫폼 기업 재평가"
매체/날짜: 파이낸셜뉴스 / 2026-06-18
기사 URL: `https://www.fnnews.com/news/202606181109249889`


[요청]

1. 기업/이슈를 한 줄로 적어 줘.
2. 기사 내용을 정확히 3줄로 요약해 줘. 한 줄은 한 문장이야.
3. 이 기사가 IT/개발 직무와 어떤 연관이 있는지 적어 줘. 직무 후보와, 그렇게 본 근거(기사에 나온 내용)를 함께 써 줘. 기사 내용에서 바로 알 수 없고 네가 추론한 내용은 "(추론)"이라고 표시해 줘.
4. 기사에 없는 수치, 날짜, 기업명, 인물, 원인은 만들어 쓰지 마. 기사에서 알 수 없는 것은 "기사에서 확인 불가"라고 써 줘.
5. 기사만으로 판단하기 어려워 따로 확인해야 하는 점이 있으면 "확인 필요"에 적어 줘. 없으면 "없음"이라고 써 줘.

[출력 형식]
반드시 마크다운 형식으로 아래 구조를 지켜서 답해 줘. 제목은 ## 로, 목록은 - 로 써 줘. 코드 블록으로 감싸지 말고 마크다운 그대로 출력해 줘.

## 기업/이슈

(한 줄)

## 3줄 요약

1. (한 문장)
2. (한 문장)
3. (한 문장)

## IT/개발 직무 연관성

- **직무**: (직무명) / **근거**: (기사 내용)

## 확인 필요

- (내용 또는 "없음")

```

**받은 결과:**

모델이 기사에 접속하지 못했는데도 제목만 보고 내용을 짐작해서 요약함. 기사에 없는 수치가 들어갔고, 접속하지 못했다는 말은 하지 않았음. "기사 본문만 근거로 하고, 접속하지 못하면 접속하지 못했다고 말해라"를 추가해서 3번 다시 시도했지만, 한 번은 "접속할 수 없습니다"라고 했고 나머지는 여전히 짐작해서 요약함.

**막힌 이유:**

모델이 URL을 열 수 있는지가 서비스와 설정에 따라 다르고, 열지 못해도 그럴듯한 문장을 만드는 것 같다. 프롬프트로는 접속 여부를 바꿀 수 없어서, 결국 기사 본문을 직접 복사해 붙여 넣는 방식으로 바꿨다. 이러면 "기사 읽는 시간을 줄인다"는 원래 목적이 조금 약해진다.
