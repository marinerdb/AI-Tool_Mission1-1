# 시스템 설계 문서

## 1. 과업 정의

- **과업**: 기업 분석을 위해, 관련 뉴스 기사를 지정한 항목(3줄 요약, IT/개발 직무와의 연관성)에 맞춰 추출·요약한다.
- **타겟 사용자**: IT/개발 직군 취업·이직을 준비하며 기업을 분석하는 사람
- **업무 문제**: 기업 분석용 뉴스를 매번 읽고 "핵심 3줄"과 "내 직무와의 관련성"을 따로 정리하는 데 시간이 걸린다. LLM에 맡기면 시간이 줄지만, 기사에 없는 수치·날짜를 지어내거나 직무 연관성을 근거 없이 단정할 위험이 있어 검증 가능한 지시문이 필요하다.
- **입력 데이터 형태**: 뉴스 기사의 제목, 매체/날짜, 본문 텍스트 (개인정보·사내 기밀 없는 공개 기사)
- **출력 규격**: 기업/이슈 1줄 + 3줄 요약(한 줄 한 문장) + IT/개발 직무 연관성(직무, 기사상 근거) + 확인 필요 사항

## 2. 페르소나

| 항목      | 내용                                                                                                      |
| --------- | --------------------------------------------------------------------------------------------------------- |
| 이름      | 뉴스 정리 리서처                                                                                          |
| 역할      | 뉴스 기사 본문에서 기업 분석에 필요한 사실을 뽑아 3줄로 요약하고, IT/개발 직무와의 연관성을 정리하는 보조 |
| 전문 분야 | 기업 뉴스 정리, IT/개발 직군 관점의 기업 분석                                                             |
| 말투      | 짧고 사실만 적는 합니다체                                                                                 |
| 금지 사항 | 기사에 없는 수치·날짜·기업명·인물·원인을 만들지 않는다.                                                   |
| 우선순위  | 사실 정확성 > 직무 연관성의 근거 > 출력 형식                                                              |

## 3. 프롬프트

### 3-1. [카테고리: 페르소나] 시스템 프롬프트

```

```

````

```
[파이낸셜뉴스] 스터닝밸류리서치는 18일 현대오토에버에 대해 인공지능(AI), 로보틱스 시대 수혜가 기대된다고 분석했다. 다만 투자의견과 목표 주가는 제시하지 않았다.

스터닝밸류 리서치는 "특히 현대차그룹이 적극 투자하고 있는 보스턴 다이나믹스(Boston Dynamics)의 차세대 휴머노이드 로봇 아틀라스(Atlas)가 상용화 단계에 진입할 경우 제조 현장의 디지털 전환 속도는 더욱 빨라질 것으로 예상된다"라면서 "이에 따라 로봇 운영 데이터 관리, 제조 AI, 디지털 트윈, 클라우드 기반 생산 시스템 등 제조 IT 인프라의 중요성도 함께 확대될 전망"이라고 밝혔다.

이어 "동사는 그룹 내 차량 및 제조 IT 인프라 구축 경험을 바탕으로 스마트 제조 환경 구축 과정에서 핵심 역할을 수행하고 있다"라며 "생성형 AI 기반 개발환경 자동화, OTA 업데이트 플랫폼, 대규모 데이터 처리 기술 등을 보유하고 있어 차세대 제조 플랫폼 시장 성장의 수혜가 기대된다"라고 부연했다.

특히 스마트팩토리에서 로봇 AI 플랫폼으로 성장 영역이 확대중인 점을 호재로 꼽았다.

실제 동사는 현재 현대차·기아 글로벌 생산기지를 중심으로 스마트팩토리 구축 사업을 수행하고 있으며 미국, 유럽, 인도, 동남아 생산거점까지 디지털 제조 솔루션 공급 범위를 확대하고 있다.

스터닝밸류리서치에 따르면 향후 휴머노이드 로봇이 자동차 생산 공정에 본격 도입될 경우 생산설비 중심의 스마트팩토리 시장은 AI 기반 자율 제조 플랫폼 중심으로 진화할 가능성이 높다. 현재 현대오토에버는 그룹 내 디지털 인프라 구축 경험과 제조 데이터 운영 역량을 기반으로 스마트 제조 플랫폼 시장에서 경쟁력을 강화할 것으로 전망된다.

스터닝밸류리서치는 "또한 생성형 AI 기반 소프트웨어 개발 자동화와 제조 데이터 분석 수요가 증가하면서 기존 IT 서비스 기업에서 AI·데이터 플랫폼 기업으로의 가치 재평가 가능성도 존재한다"라고 덧붙였다.

한편 동사는 현대차그룹의 핵심 IT 서비스 기업으로 차량 소프트웨어, 클라우드, 스마트팩토리, 데이터 플랫폼 및 AI 솔루션을 통합 제공하고 있다. 과거 그룹 전산 시스템 구축 중심 사업에서 벗어나 최근에는 SDV 플랫폼, 디지털 트윈, 생성형 AI, 스마트 물류 솔루션 등 미래 산업의 핵심 기술 영역으로 사업 포트폴리오를 확대하고 있다.
````

## 4. Few-shot 예시 (3건)

### 예시 1 (일반 입력)

입력:

```
[기사]
기사 제목: 가나다소프트, 클라우드 사업부 신설
매체/날짜: 예시일보 / 2026-01-05
기사 본문: 가나다소프트는 5일 클라우드 사업부를 신설하고 올해 개발 인력 200명을 채용한다고 밝혔다. 신설 사업부는 사내 서버를 클라우드로 옮기는 서비스를 주력으로 한다. 회사는 3년 안에 관련 매출 비중을 30%까지 높이겠다고 했다.
(이하 [요청], [출력 형식]은 3-3 템플릿과 동일)
```

출력:

```
## 기업/이슈

가나다소프트, 클라우드 사업부 신설

## 3줄 요약

1. 가나다소프트가 5일 클라우드 사업부를 신설했습니다.
2. 신설 사업부는 사내 서버를 클라우드로 옮기는 서비스를 주력으로 합니다.
3. 회사는 올해 개발 인력 200명을 채용하고 3년 안에 관련 매출 비중을 30%까지 높이겠다고 밝혔습니다.

## IT/개발 직무 연관성

- **직무**: 클라우드/인프라 개발 / **근거**: 사내 서버를 클라우드로 옮기는 서비스가 주력이라고 함
- **직무**: 백엔드 개발 (추론) / **근거**: 개발 인력 200명 채용 계획이 있으나 세부 직무는 기사에서 확인 불가

## 확인 필요

- 채용 직무별 인원과 일정은 기사에서 확인 불가
```

## 5. Zero-shot vs Few-shot 비교

### Zero-shot 시도

- 입력: 시스템 프롬프트와 [요청] 5개 항목만 넣고 예시는 넣지 않음. 기사는 현대오토에버 기사(3-2)를 사용함.
- 결과: 3줄 요약은 만들었으나 한 줄이 두 문장인 경우가 있었음. "IT/개발 직무 연관성"에서 "(추론)" 표시를 빼먹고 "백엔드 개발자가 필요함"처럼 기사에 없는 내용을 단정함. "확인 필요" 항목에는 보통 "없음"만 적음.

### Few-shot 적용

- 입력: 4번 항목의 예시 3건(일반 입력, 직무 연관성이 없는 입력, 되묻는 흐름)을 함께 넣음.
- 결과: 한 줄 한 문장 형식과 출력 구조가 더 안정적으로 지켜짐. 직무 연관성에 "(추론)"을 붙이는 경우가 늘었고, 기사에 없는 내용은 "기사에서 확인 불가"로 적음.

### 단계적 추론 유도 추가 여부

추가하지 않음. 이 과업은 기사에서 사실을 뽑아 요약하는 일이라 긴 추론 과정이 필요하지 않다. 단계적 추론을 시키면 오히려 기사에 없는 내용을 추론해서 덧붙일 위험이 커진다고 판단했다. 직무 연관성처럼 추론이 필요한 부분은 "(추론)" 표시 규칙으로 따로 관리했다.

## 6. 검증 전략 (대화 시작 전 작성)

다음 대답을 사실 오류로 의심한다.

1. **가정·전망을 사실로 바꾼 경우**: 이 기사는 "상용화 단계에 진입할 경우", "~가능성", "~전망"처럼 조건이나 예측 표현이 많다. 이를 이미 일어난 일로 요약하면 오류로 본다.
2. **누가 한 말인지 빠뜨린 경우**: 전망의 주체(스터닝밸류리서치)를 쓰지 않고 일반적인 사실처럼 쓰면 의심한다.
3. **기사에 없는 정보를 채운 경우**: 수치, 날짜, 기업명, 인물, 원인 등이 본문에 없으면 오류로 본다. 특히 영업이익, 상용화 시점, 기자명처럼 기사에 없는 정보를 물었을 때 모른다고 하지 않고 답하면 오류다.
4. **원인과 결과를 잘못 연결한 경우**: 재평가 가능성의 이유처럼 기사의 인과관계를 다른 이유로 바꿔 쓰면 오류로 본다.
5. **추론을 사실처럼 쓴 경우**: 기사에서 바로 알 수 없는 직무 연결에 "(추론)" 표시가 없으면 지시 위반으로 본다.
   확인 방법: 기사 원문을 보며 직접 대조하고, 정답을 아는 질문(7번)으로 Pass/Fail을 판정한다. 같은 질문을 두 번 입력해 답이 같은지도 확인한다.

### v2에서 수정한 내용과 이유
